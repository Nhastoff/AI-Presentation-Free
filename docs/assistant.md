# AI помощник

## Подключение на MacBook

1. Установите Codex Desktop в `/Applications` или `~/Applications`. Альтернатива — Codex CLI в PATH, `/opt/homebrew/bin` или `/usr/local/bin`.
2. Откройте кнопку «AI» в отдельной полосе справа сверху → «Подключить» → «Войти». Та же кнопка сворачивает панель и не перекрывает команды редактора.
3. Завершите штатный вход ChatGPT в браузере.
4. Введите запрос, например «Создай 5 слайдов о Японии, добавь таблицу бюджета и заметки выступающего».
5. Проверьте предпросмотр крупных изменений и примените их. Простые правки применяются сразу и отменяются в чате либо Cmd+Z.

Отмена из чата восстанавливает снимок до конкретной AI-правки, включая слайды и изображения. Выбор объекта без изменения содержимого не мешает отмене. Если после AI-правки вы изменили документ вручную, используйте обычную отмену редактора, чтобы сохранить порядок правок. Карточка показывает «Отменено» только после подтверждения редактором; отмена и повтор в редакторе также обновляют её статус. Снимки отмены доступны в текущем запуске, для последних 20 AI-изменений; история переписки после перезапуска не заменяет резервную копию проекта.

Используется отдельный процесс Codex, не открытая переписка настольного приложения. Вход хранится штатным Codex в отдельном профиле приложения. Секреты не передаются редактору. Отдельный API-биллинг не используется. Запросы и необходимые материалы обрабатываются сервисом ИИ через интернет.

## Возможности и ограничения

- Текст, фигуры, изображения, группы, порядок объектов, ссылки, анимации, заметки, комментарии. Таблицы и диаграммы — редактируемые группы примитивов; нативные Office Charts/SmartArt не поддерживаются моделью редактора.
- Экспорт проекта/PPTX/PDF и показ используют существующие действия редактора; импорт вложенной презентации требует подтверждения.
- До 8 файлов за выбор, 20 МБ на файл, 40 МБ суммарно. PDF: до 100 страниц и 120 000 символов, без OCR. DOCX: текст основного документа до 120 000 символов. Сложная исходная вёрстка не сохраняется.
- Изображения вставляются по идентификатору вложения. Галочка у файла включает отправку изображения для анализа. Отдельный переключатель «Генерировать изображения в этом запросе» разрешает встроенный генератор Codex на один запрос и затем сбрасывается. Отдельный API-ключ не используется. Доступ зависит от версии Codex, модели, аккаунта и оставшихся лимитов.
- Генерация расходует общие лимиты Codex. По [документации OpenAI](https://learn.chatgpt.com/docs/image-generation), запросы с генерацией могут расходовать включённые лимиты примерно в 3–5 раз быстрее похожих запросов без неё. По умолчанию помощник создаёт не более одной картинки и переиспользует готовые. Токены в панели — данные Codex, а не процент оставшейся подписки.
- Сгенерированные изображения хранятся локально в `assistant/generated-assets`, реестр по разговорам — `assistant/generated-images-index.json`. Модель получает идентификаторы без base64; картинка встраивается в проект и PPTX. Восстановление старого изображения не запускает повторную генерацию.
- Материалы текущей сессии хранятся в памяти; после перезапуска их нужно прикрепить заново.
- Экономия: краткая структура, нужные слайды, чтение вложений по запросу, пакетные операции, локальная проверка. Режимы меняют поддерживаемый уровень рассуждений модели; одинаковые настройки возможны, если модель не поддерживает разные уровни.
- История: пользовательский каталог приложения `assistant/history`; служебные сессии: `assistant/threads.json`; авторизация: `assistant/codex-profile`. Эти данные не входят в презентации и экспорт.
- Очистка истории убирает отображаемые разговоры. Для полного удаления данных закройте приложение и удалите каталог `assistant` в его пользовательском хранилище. Отключение завершает процесс и не выполняет выход из аккаунта.

## Проверки

`pnpm test`, `pnpm test:e2e`, `pnpm build`, `pnpm test:desktop`.

Для упакованного macOS приложения задайте `PF_ELECTRON_EXECUTABLE` на `Contents/MacOS/AI Presentation Free` внутри `.app`; `PF_CODEX_SMOKE_REQUIRED=1` требует инициализации установленного Codex. Smoke-проверка использует временный профиль без входа и без запросов к модели.

Вручную на MacBook: вход в браузере, первый запрос и повторный после перезапуска, создание и подтверждение презентации, отмена, вложения, экспорт и показ. CI проверяет запуск на архитектуре runner, не на всех моделях Mac.

Реальная проверка 0.3.1 на Windows выполнена через штатный вход пользователя в ChatGPT: Codex создал презентацию «Выходные в Киото» из трёх слайдов, один раз сгенерировал PNG и вставил его на обложку. Проверен экспорт PPTX с тремя слайдами, редактируемыми фигурами и встроенным изображением. Учётные данные и результаты частной проверки в репозиторий не включаются.
