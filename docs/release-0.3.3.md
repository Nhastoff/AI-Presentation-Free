# AI Presentation Free 0.3.3

Собраны исправления после версии 0.3.1:

- Кнопка AI перенесена в отдельную узкую полосу справа сверху. Она открывает и сворачивает помощника, не перекрывая «Сохранить проект», поле ввода и другие команды редактора. Изменение ширины чата учитывает эту полосу.
- Исправлена отмена AI-изменений: после замены всей презентации восстанавливаются исходные слайды, текст, оформление и изображения. Щелчок по объекту без изменения содержимого больше не поглощает отмену.
- Надпись «Отменено» появляется после подтверждённого восстановления документа. Состояние карточек синхронизируется с обычной отменой и повтором. Проверка версии документа защищает ручные правки от перезаписи.

Проверки включают разные размеры окна и состояния панели, полную замену презентации с отменой и повтором, а также защиту ручных изменений. На Windows дополнительно проверен сценарий «3 слайда Киото с иллюстрацией → 4 слайда Hearthstone → отмена» в собранном приложении: исходный проект восстановлен точно. CI собирает Windows и macOS, запускает упакованное приложение на macOS, проверяет экспорт изображения в PPTX и отмену замены презентации.

Сборки: Windows x64 (установщик и переносимая версия), macOS Apple Silicon (arm64) и Intel (x64). Генерация изображений через Codex с входом ChatGPT, без отдельного API-ключа, сохранена. Сборки macOS не подписаны Developer ID и не нотарифицированы Apple. Авторизованную генерацию на конкретном MacBook нужно проверить после установки; CI не использует личный аккаунт.
