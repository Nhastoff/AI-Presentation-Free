# AI Presentation Free 0.3.0

ИИ-помощник в правой боковой панели: потоковые ответы, локальная история по презентациям, вложения и режимы «Экономно / Обычно / Качественно».

Подключение к локальному Codex App Server со штатным входом в ChatGPT; отдельный API-ключ не нужен. Используется отдельный профиль помощника: при первом подключении нажмите «Войти» даже при выполненном входе в Codex Desktop. Это отдельная сессия, а не управление открытым окном Codex.

Помощник создаёт и меняет редактируемые слайды, объекты, таблицы и диаграммы, использует заметки, оформление, экспорт и показ. Небольшие изменения применяются сразу; крупные и разрушительные требуют предпросмотра. Проверка версии документа защищает ручные правки; изменения поддерживают отмену.

PDF, DOCX, PPTX, проекты, текстовые файлы и изображения доступны как вложения. Текст извлекается локально и читается моделью по необходимости. Анализ изображения включается отдельно. Поиск в интернете — через Codex. Генерация изображений в этой версии не подключена; готовые изображения можно прикрепить и вставить. PDF без текстового слоя требует предварительного OCR.

На Mac установите Codex Desktop в папку «Программы» либо Codex CLI. Затем откройте помощника → «Подключить» → «Войти». Нужны интернет и доступные пользователю возможности Codex. Режимы используют реальные поддерживаемые уровни рассуждений; фиксированная экономия лимитов не обещается.

Сборки: macOS Apple Silicon (arm64), macOS Intel (x64), Windows. Публикация выполняется после тестов и запуска упакованного приложения на macOS с реальным Codex App Server без авторизации. Авторизованную генерацию и браузерный вход необходимо дополнительно проверить на пользовательском MacBook. Сборки не подписаны Developer ID и не нотарифицированы Apple.
