# Проверка версии 0.2.0

18 октября 2026 года, Windows 10 x64. Node.js 24.19.0, Electron 44.9.0, electron-builder 26.15.3.

- 14 модульных тестов прошли: модель, безопасность/нормализация проектов, сохранение, таблицы/диаграммы, эффекты, геометрия групп, распределение объектов, повороты/отражения, импорт преобразований PPTX. Отдельно проверены исправления композиции неравномерного масштаба с поворотом и нормализации угла.
- Все 9 браузерных сценариев прошли одним запуском в Microsoft Edge: редактирование, история, сохранение/JSON, показ, PPTX, тема/макеты, лимиты распаковки, лента, перемещение/размер, SVG, группировка/разгруппировка, выравнивание/распределение, нативные p:grpSp и обратный импорт, колонтитулы, буквальная замена, комментарии, скрытые слайды.
- Vite production build успешен. Созданы установщик NSIS и Portable EXE Windows x64 версии 0.2.0.
- Desktop smoke прошёл в Electron и повторно в release/win-unpacked: создание слайда Ctrl+M, отмена Ctrl+Z. Для упакованного приложения дополнительно проверены Ctrl+G/Ctrl+Shift+G. Создан настоящий PDF 46 108 байт, ошибок renderer не зарегистрировано. Подтверждены nodeIntegration=false, contextIsolation=true, sandbox=true.
- Проверка установочного сценария NSIS на чистой Windows и запуск Portable EXE на другом компьютере не выполнялись. Проверка unpacked EXE подтверждает запуск упакованного кода, но не заменяет эти проверки.
- macOS: общий код и CI для Intel/Apple Silicon подготовлены; сборка и запуск на Mac в этой среде не проверены. electron-builder не поддерживает macOS-сборку из Windows.

Поставляемые EXE не имеют коммерческой подписи; нотарификация Apple не выполнялась. Контрольные суммы артефактов — release/SHA256SUMS.txt.

Исследования REA/Ghidra завершены экспортом Evidence и закрытием сеансов. Поведенческая совместимость всего PowerPoint не заявляется: [границы реконструкции](reconstruction-progress.md), [матрица функций](compatibility.md).
