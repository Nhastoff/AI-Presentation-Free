# Возможности и совместимость

AI Presentation Free 0.2.0 — первая самостоятельная реализация редактора с привычной лентой команд. Это не полная функциональная замена всех выпусков PowerPoint.

| Область | Реализовано | Ограничения |
| --- | --- | --- |
| Интерфейс | Вкладки Файл, Главная, Вставка, Дизайн, Переходы, Анимация, Показ слайдов, Рецензирование, Вид и контекстная вкладка Формат; стандартное расположение миниатюр, рабочего слайда, заметок и ленты | Порядок групп выбран для привычного процесса работы. Точные координаты кнопок PowerPoint из бинарников не восстановлены |
| Слайды | Создание, копирование, удаление, перестановка, четыре макета, цвет фона, скрытие, колонтитулы и номера | Размер документа пока фиксирован: 16:9, 1280×720 |
| Объекты | Текст, прямоугольники, эллипсы, линии, растровые изображения; перемещение, размер, поворот, слои, множественный выбор, группировка/разгруппировка/перегруппировка, выравнивание, распределение, отражения, копирование/вставка | Группы плоские; нет обрезки изображений, точек редактирования фигур и сложных эффектов |
| Текст | Шрифт, размер, жирный, курсив, подчёркивание, цвет, выравнивание, простые маркеры, поиск/замена, копирование формата | Форматирование всего текстового блока; нет смешанных стилей отдельных слов, формул и WordArt |
| Таблицы | Сетка и подписи создаются из редактируемых объектов | Нет единой структуры таблицы, объединения ячеек и табличных стилей Office |
| Диаграммы | Столбчатый график по введённым числам и подписям | Снимок из фигур и текста; нет связанного Excel, живого редактора данных и остальных типов диаграмм |
| Показ | Полный экран, начало/текущий слайд, клавиатура; переходы без эффекта/выцветание/сдвиг; вход объектов появление/выцветание, пропуск скрытых слайдов, HTTP(S) гиперссылки | Нет временной шкалы, триггеров, Morph, режима докладчика на втором экране и записи выступления |
| Проект | JSON, локальное автосохранение, история отмены/повтора | Один автоматически восстанавливаемый документ на устройство; JSON нужен для сохранения нескольких проектов |
| PPTX | Экспорт редактируемого текста, фигур, изображений, заметок, нативных групп, скрытых слайдов и гиперссылок; импорт обычных объектов, части тем и геометрии заполнителей из макетов | Экспорт статичный. Вложенные группы уплощаются; сдвиг при неравномерном масштабе и повороте приближается с предупреждением. Не поддерживаются полностью диаграммы Office, SmartArt, градиенты, мультимедиа, анимации, произвольные внешние связи, шрифты и все мастер-макеты. Импорт может потерять неподдержанные объекты |
| Рецензирование | Комментарии: создание, завершение, повторное открытие, удаление | Сохраняются в JSON AI Presentation Free; обмен комментариями через PPTX не реализован |
| PDF | Настольный экспорт с системным выбором файла | Статичные слайды без анимации |
| Платформы | Windows x64; общий Electron-код и CI для macOS Intel/Apple Silicon | Windows проверена локально. macOS требует отдельной сборки и проверки на Mac; опубликованных подписанных сборок пока нет |

Пока не реализованы VBA/надстройки, совместное редактирование, облачное хранение, совместное рецензирование, мастер слайдов как редактор, видео/аудио, встроенные объекты OLE, полноценная печать раздаточных материалов и полная доступность PowerPoint.

## Проверка

Автоматически проверяются модель, безопасная загрузка проектов, сохранение эффектов, таблицы/графики, основные действия ленты, перемещение/размер объектов, история, JSON, показ, PPTX экспорт и обратный импорт, наследование темы и геометрии макета, ограничение распаковки архивов. Отдельный desktop smoke запускает Electron, проверяет изоляцию renderer и реальное создание PDF.

Источники исследования установленной версии Office 2007: [research.md](research.md). Исследование не устанавливает полную совместимость с PowerPoint.

Колонтитулы экспортируются как обычные текстовые объекты; динамические заполнители мастера не создаются. 42 команды приложения сопоставлены с именами idMso по статическим таблицам MSO. Это метаданные сопоставления, а не доказательство одинакового поведения или расположения кнопок. Подробности: [reconstruction-progress.md](reconstruction-progress.md).
