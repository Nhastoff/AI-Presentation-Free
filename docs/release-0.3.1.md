# AI Presentation Free 0.3.1

Встроенная генерация изображений через локальный Codex с входом ChatGPT, без отдельного API-ключа. Включите «Генерировать изображения в этом запросе» и попросите создать презентацию с иллюстрацией. По умолчанию генерация выключена; после отправки переключатель сбрасывается. Изображения расходуют общие лимиты Codex.

Панель называется «AI помощник»; отдельная постоянная кнопка «AI» разворачивает и сворачивает её. Текущий провайдер подключения — Codex. Другие провайдеры в этой версии ещё не подключены.

Результат показывается в чате и доступен помощнику для вставки и замены изображений на слайдах. Картинки сохраняются локально, восстанавливаются в своём разговоре и встраиваются в проект/PPTX. Модель получает идентификаторы вместо base64. Поддержаны сообщения об ошибках и лимитах генерации.

Исправлены передача инструментов при первом входе через ChatGPT и дублирование моделей при одновременном обновлении аккаунта.

Проведена реальная проверка на Windows через аккаунт ChatGPT: три слайда «Выходные в Киото», одна сгенерированная PNG-иллюстрация, её вставка на обложку и экспорт PowerPoint с редактируемым текстом и встроенным изображением. CI дополнительно проверяет сборки Windows/macOS и запуск упакованного приложения с Codex на macOS без авторизованной генерации. Сам вход и генерацию на конкретном MacBook нужно проверить после установки.

Сборки: macOS Apple Silicon и Intel, Windows. Для генерации нужен актуальный Codex Desktop или CLI, интернет и доступная функция генерации в аккаунте. Сборки macOS не подписаны Developer ID и не нотарифицированы Apple.
