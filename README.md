# AI Presentation Free 0.2.0

Свободный настольный редактор презентаций с собственным интерфейсом и форматом проекта. Приложение работает локально: презентации и изображения не отправляются на сервер.

Это самостоятельный редактор на ранней стадии разработки. Логотип и интерфейс созданы для AI Presentation Free. Функциональная совместимость с PowerPoint ограничена поддержанными возможностями импорта и экспорта; сложные эффекты, встроенное видео, макросы, SmartArt и все варианты оформления Office не воспроизводятся.

Лента следует привычной организации PowerPoint: вкладки и группы команд сверху, миниатюры слева, слайд в центре, заметки снизу. Точное совпадение координат всех кнопок и их динамической видимости не подтверждено. Подробная [матрица возможностей и ограничений](docs/compatibility.md), [прогресс восстановления](docs/reconstruction-progress.md), [результаты анализа REA + Ghidra](docs/research.md).

## Новое в 0.2.0

- Множественное выделение с Shift, Ctrl или Cmd; группировка, разгруппировка и повторная группировка.
- Выравнивание объектов относительно выделения или слайда, распределение по горизонтали и вертикали, отражение, поворот на 90° и изменение порядка слоёв.
- Примечания к слайдам с отметкой решения и удалением; скрытые слайды, пропускаемые при показе.
- Нижний колонтитул, заданная пользователем дата и номера слайдов; исключение титульного слайда.
- Копирование оформления, гиперссылки и замена текста; сопоставления части команд с фактическими идентификаторами MSO.

Для группировки используйте Ctrl+G (Cmd+G на macOS), для разгруппировки — Ctrl+Shift+G (Cmd+Shift+G). Распределение требует не менее трёх объектов или групп. Примечания сохраняются в собственном файле проекта; их перенос в PPTX пока не поддержан. Колонтитулы создаются как редактируемый текст; автоматическое обновление даты и поведение всех образцов Office не воспроизводятся. Сложные вложенные преобразования групп при импорте PPTX могут быть приближены.

Исследование установленного Office12 охватывает [обработчики PPCORE](docs/powerpoint-command-handlers.md), [рисование и команды OART](docs/powerpoint-oart-analysis.md) и [общую ленту и команды MSO](docs/powerpoint-mso-analysis.md). В MSO сверены две таблицы по 4 353 пары ID/имя; между PPCORE и OART подтверждены маршруты создания команд выравнивания, распределения и группировки. Эти факты помогают проектировать привычные команды, но не доказывают полное восстановление PowerPoint, его математических алгоритмов или версии для macOS. Код редактора написан независимо.

## Запуск

Нужен Node.js 24.15+ и pnpm 11.25 (`corepack enable` и `corepack prepare pnpm@11.25.0 --activate`).

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Для разработки запустите `pnpm dev`, затем во втором терминале:

```powershell
$env:PRESENTATION_FREE_DEV_URL = 'http://127.0.0.1:5173'
pnpm start
```

На macOS: `PRESENTATION_FREE_DEV_URL=http://127.0.0.1:5173 pnpm start`.

Редактор можно открыть в обычном браузере через `pnpm dev`. Настольная оболочка предоставляет системный диалог сохранения PDF; в браузере используется печать.

## Сборки Windows и macOS

```powershell
pnpm dist:win
```

Создаёт установщик NSIS и переносимый `.exe` в `release/`. Для полноценной сборки используйте Windows.

```sh
pnpm dist:mac
```

На Mac создаёт DMG для Intel x64 и Apple Silicon arm64. Сборка macOS должна выполняться и проверяться на macOS; сборка из Windows не подтверждает её работоспособность. GitHub Actions `.github/workflows/build.yml` собирает обе платформы вручную или при публикации тега `v*` и сохраняет установщики как artifacts.

Текущие сборки не подписаны коммерческими сертификатами и не нотарифицированы Apple. Windows и macOS могут показывать предупреждения о неизвестном разработчике. Для публичного распространения нужны отдельные сертификаты, подпись и проверка на целевых системах.

## Проверки

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Модульные проверки охватывают модель презентации и обмен файлами. Браузерные проверки предназначены для основных действий редактора; они не заменяют проверку упакованного приложения на Windows и macOS.

## Архитектура

- `src/` — редактор и модель презентации, Vite.
- `electron/` — изолированная настольная оболочка и экспорт PDF.
- `assets/logo.svg` — оригинальный логотип.
- `tests/` — проверки.
- `release/` — результаты упаковки.

В renderer отключён Node.js, включены `contextIsolation` и sandbox. Preload предоставляет только платформу и запрос экспорта PDF. PDF печатается в отдельном скрытом окне с отключённым JavaScript и сетевыми запросами. Внешние HTTP(S) ссылки открываются в системном браузере.

Разработка выполнена как самостоятельная реализация. Исходный код, бинарные компоненты, ресурсы и торговые обозначения Microsoft не входят в приложение.
